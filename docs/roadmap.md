# ChoreQuest Roadmap

## Project Vision

ChoreQuest is being developed incrementally using an agile approach. Each sprint delivers a working improvement while progressively demonstrating enterprise application development using Microsoft Power Platform and PostgreSQL.

---

# Sprint 0 – Project Foundation

## Objectives

- Create GitHub repository
- Configure Git workflow
- Establish project structure
- Define documentation standards

## Deliverables

- Repository created
- GitHub configured
- VS Code workspace
- Initial documentation

Status: Completed
