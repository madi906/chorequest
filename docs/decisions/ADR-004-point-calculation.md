# ADR-004: Point Calculation

## Status

Accepted

## Decision

Points are awarded only after a parent approves a completed chore.

Rejected chores receive no points.

Every approved award creates a Point Transaction record.

## Consequences

The points ledger becomes auditable and prevents accidental changes to historical scores.
