Title:
Why ChoreQuest starts with PostgreSQL instead of SharePoint

Status:
Accepted

Context:
The project requires a free, scalable relational database suitable for learning modern application architecture.

Decision:
Use Supabase PostgreSQL.
Expose data through REST APIs.
Power Apps consumes APIs.
Future versions will migrate selected functionality to SharePoint Online and Dataverse for comparison.


Consequences

Pros:
Free
Real PostgreSQL
Enterprise database
API-first architecture

Cons:
More setup
Requires API integration
