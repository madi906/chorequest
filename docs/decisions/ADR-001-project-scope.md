# ADR-001: Project Scope

## Status

Accepted

## Context

The objective is to build a portfolio project that demonstrates Microsoft Power Platform development skills while remaining simple enough to complete independently.

## Decision

The first release (MVP) will include:

- Household management
- Parent and Child users
- Chore templates
- Chore assignments
- Point tracking

The following features are intentionally postponed:

- Rewards redemption
- Badges
- Notifications
- AI recommendations
- School mode

## Consequences

The MVP stays achievable while leaving room for future enhancements.
