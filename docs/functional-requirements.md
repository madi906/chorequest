ChoreQuest Functional Requirements

1. Introduction
   
Purpose

ChoreQuest is a gamified household task management application that helps parents encourage responsibility through chores, points and rewards.

The application is designed to work on both desktop and mobile devices and follows enterprise software architecture principles.

2. Scope

Version 1.0 includes:

Household management
Parent management
Child management
Chore management
Chore assignment
Chore approval
Point tracking
Leaderboard

Future versions include:

Rewards
Badges
AI
Notifications
Schools
Multi-household SaaS

3. Actors
   
Parent:

Create chores
Assign chores
Approve chores
View leaderboard

Child:

View chores
Complete chores
View points

1. Functional Requirements
   
FR-001 - Create Household
The system shall allow a parent to create a household.

FR-002 - Add Parent
The system shall allow parents to invite other parents.

FR-003 - Add Child
The system shall allow parents to add children.

FR-004 - Create Chore
The system shall allow parents to create reusable chores.

FR-005 - Assign Chore
The system shall allow parents to assign chores.

FR-006 - Do Chore
The system shall allow children to complete chores.

FR-007 - Approve Chore
The system shall allow parents to approve chores.

FR-008 - Award Points
The system shall automatically award points.

FR-009 - Leaderboard
The system shall display a leaderboard.

FR-010 - Points
The system shall record all point transactions.
